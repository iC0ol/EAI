# D Gate 1 判断

结案日期：2026-10-23，Asia/Shanghai。**Stop at Gate 1；当前不建议进入 Gate 2。**
原因是闭环退化的统计证据不足，并有一次训练执行中断；没有证据表明后验监督
机制已被简单方法否定，也没有证据支持其必要性。没有训练任何对齐后验策略。

## 实际完成范围

固定一个 Square PH 低维任务，三个条件、训练种子 42/43，共启动 **6 次**策略训练。
五次完成 50,000 更新并各执行 50 个完整 400 步正常时轴回合，共 **250 回合**。
Larger-Lag seed 43 最后确认 42,400 更新，进程与最终 checkpoint 均不存在；
没有捕获退出状态/traceback，终止原因未知，不能归因为硬件、OOM 或数值发散。
原始记录与耗时下界见 [中断证据](interruption.json)。没有第七次尝试或部分模型评估。

| 条件 | seed 42 | seed 43 | Clean−污染配对差（pp）及初态 bootstrap 95% CI |
|---|---|---|---|
| Clean | 22/50，44% | 34/50，68% | 基准 |
| Mixed Small Lag | 19/50，38% | 27/50，54% | seed 42：6，[-8,22]；seed 43：14，[-4,32] |
| Larger-Lag Control | 22/50，44% | 训练中断，未测试 | seed 42：0，[-16,16]；seed 43：缺失 |

五次完整训练占用 GPU 墙钟 1.6385 h；中断训练已确认 ≥0.2668 h，合计 ≥1.9053 h。

## Q1：是否存在实质影响

**`Insufficient evidence / Stop at Gate 1`。**

Mixed 的两个训练种子点估计方向一致，平均下降 10pp；按共同测试初态聚类的
bootstrap 95% CI 为 **[-3,22]pp**。这支持报告一个待确认的退化趋势，但未满足
预登记的“两个种子均下降至少 10pp，且每种子配对 CI 下界大于零”。不能把
这次观察写成已证明实质损害，也不能把区间包含零写成无害：区间仍容许较大的损害。

Larger seed 42 与 Clean 的总成功数相同，但逐初态发生 9 个 Clean-only 与
9 个污染-only 成功，不是逐回合行为完全相同。它没有显示预期的正向幅度效应；
种子 43 缺失，无法判断重复性，更不能宣称 ±4 步普遍无害。

Clean 的 44%/68% 通过预先固定的近失败/天花板操作门槛（≤5/50 或 ≥48/50
即停止），证明正常控制下能完成任务；**不代表该管线有足够统计功效**。
两个 Clean 种子相差 24pp。训练 noise MSE 降至约 0.011，EMA clean-valid
先降后升至约 0.21，存在明显过拟合迹象。未根据该曲线挑早期 checkpoint、
重新训练、改污染或任务。训练 loss 的收敛不能替代闭环成功证据。

这些区间针对本次固定策略的 50 个初态；两个训练种子不能确定训练总体方差。
本次样本量也无法排除 1–3pp 的小效应。结论限于人工合成、50% episode 固定
平移、当前小型相对动作 DP，不支持所有模仿学习系统或真实日志分布的推断。

## Q2：简单方法能否恢复偏移

**未评估：Step C 未达到进入 Step D 的门槛。**

没有实现或执行互相关、ARX、时间序列对齐或置信度估计，没有 lag recovery
准确率、步/毫秒误差、多解率、动态/近常量分段结果可报告。按要求不创建
`lag_identification.md`。保留的 8 条同步锚点与 16 条独立 lag test 示教未用于估计。

数据测试确认已知真值逆移后公共窗口逐值恢复，这只证明**生成器与 Oracle
定义正确**，不构成盲估计器恢复证据。不能据此给出
`No-Go for posterior-supervision necessity in this setting`，也不能声称存在
可靠的非尖锐 lag 后验、不可靠硬对齐或被证明有用的模糊示教。

## 停止原因区分与适用边界

| 类别 | 当前证据 |
|---|---|
| 官方环境/数据部署失败 | 否；固定版本可运行，官方低维数据哈希吻合，5 个策略完成闭环 |
| 执行完整性问题 | 是；第六次训练中断，无最终权重，Larger 第二种子缺失 |
| 统计证据不足 | 是；Mixed CI 跨零，Larger 对照不完整 |
| 简单基线否定后验机制必要性 | 未检验，不得宣称 |
| 数据/模型条件问题 | 原始相对 object 特征依赖缓存；训练前排除该 7 维，选取 16 维原始同步状态；另有明显过拟合及种子方差限制 |

实际时间约定为 `obs[t]=O(s_t)`，相对 OSC 控制命令 `actions[t]` 驱动
`s_t → s_(t+1)`，`next_obs[t]=O(s_(t+1))`；20Hz、每步 50ms。
`C[t]=A[t+delta]` 的正号表示后续命令被提前写作标签，±1/2/4 步即
±50/100/200ms；正常控制器响应与测试推理时轴保持一致。
训练前排除的相对 object 缓存派生项及最后 next_obs 的提取方式见
[时间约定与证据](data_time_convention.md)。原始 HDF5 与保留输入分量均未改写。
低维状态实验不证明 RGB 时间戳错误下的视觉策略表现。

本轮交付后停止。**当前不 Go to Gate 2** 的依据是前提尚未得到足够证据，
不是后验监督已经无效或简单方法已经解决问题。不自动追加种子、改变固定预算、
调参、继续 Gate 1 重跑，或进入后验监督训练；等待研究者审阅现有结果。
