## 2. Gate 0-A：可信的专家示教状态分叉（未通过不准开展 B）

### 2.1 分叉对象与主实验时序

## 4. 指标、解释基线与不得逾越的统计范围

### 4.1 正确的结果定义

`Y(s,a;π)∈{0,1}` 是从**同一分叉状态**先执行动作 `a`、随后交给固定 `π` 的官方终局成功指标。`Δ_loss(s,δ;π)=Y(s,a*;π)-Y(s,a*+δ;π)`。

- `+1`：扰动令原本成功变失败；`0`：当前配对下结果未变；`−1`：扰动令原本失败变成功（**改善型扰动**）。不把单条差当连续无噪声损失、解析Q Hessian或泛化价值函数。
- 对 `+δ` 与 `−δ` 同一模长测符号非对称，避免自动将其合并；在同一状态内比较等模长不同方向并报告完整配对。
- 任务到目标的距离、末端与peg轴角度、碰撞/接触代理和恢复步数属于**辅助指标**，不得取代官方终局成功。`ncon>0` 仅是接触存在的粗代理，不是精确法向/任务接触模式。
- 完整记录有效状态、来源 episode、策略checkpoint、方向/符号和半径。B1 12状态并不是84个独立状态；全部120是相关后缀，按**episode→state** 层级报告分布和原始配对，不能把单状态多个方向伪装成独立样本。给描述性区间时按源轨迹聚类并诚实标明episode极少、区间很宽。

### 4.2 简单解释模型/反驳顺序

在 Gate 0 不训练深度教师；优先使用先验几何、排序、预先定义的损害模式，探索性做小容量拟合时不得把训练后结果冒充留出证据：

1. **各向同性与state-scalar**：同一状态等模长误差没有方向区别；单个状态权重只能描述该状态的总体风险。
2. **world-axis / state-independent global directional metric**：世界xyz固定方向或固定对角权重，是否已经解释大多数差异？区别“固定轴”与可旋转的全局3×3度量。
3. **fixed object-frame**：按物体局部坐标转换同一扰动，比较法向/切向或主轴方向；所有转换须有可靠位姿且和动作定义一致。
4. **fixed contact/task-frame**：优先Square的可观测peg/插入轴、任务相关几何；如果确有可靠接触法向可另外分析，**不能把环境`ncon`计数当成精确contact normal**。若无法构建可信几何规则，记录 `baseline unavailable`，不能把“它没赢”归因为M有价值。
5. **符号/改善效应**：因为对称PSD满足 `δᵀM(s)δ=(-δ)ᵀM(s)(-δ)`，若存在可重复的改善型或强正负非对称，则当前**对称、只减分PSD模型**不适用；不要临时添加线性项/非对称头挽救方向。
6. **state dependence**：固定world/object/contact坐标与一个标量状态权重以后，是否仍有方向排序随状态变化的描述性反例？dev与held-out严格按源episode隔离。v2的样本规模可能不足以比较 held-out NLL、state-shuffle 的统计差异，**不得硬要求或声称已经完成了完整Gate1的这些指标**。

**解读守则：** 固定接触系的优越性需要同一物理定义和可比的留出测试；只比较3个世界坐标轴且不测试混合方向，不能据此推断一般3×3 M(s)无价值；反之单个案例无法由固定轴解释也不能证明需要可学习状态条件M。

## 5. 预登记研究决策（工程、统计与论文必要性分开）

- `Stop/Invalid`：示教状态不能可信恢复、零扰动复现失败、动作发生未被处理的clip/随机性不同步、实验/真值边界污染。**不推断M科学假设成立或失败。**
- `No-Go for symmetric-PSD M`：跨预登记有效来源重复出现**强、方向可确认的正负非对称或改善型扰动**，与 `sigmoid(b−αδᵀMδ)` 单调、正负对称假设不符；当前40参数对称PSD方法停止，不自动添加非对称机制。但这**不证明所有方向感知学习都不可行**。
- `No-Go / simple explanation sufficient`：在有足够信息量的独立留出状态与方向上，**可信** fixed-world/object/contact-frame 或 state-independent 解释已足够，并没有值得新学习方法消除的残差；说明证据强度，不因本轮小样本强行给统计排除结论。或发现现象是控制/采样伪差。
- `Potential Go to a separately registered Gate 1`：至少不同来源的多处状态看到可信的方向性下游后果，且held-out混合方向有与固定几何/标量解释不完全重合的预定反例；对称PSD没有明显不适用证据，并有初步重放稳定性。此结论**只批准讨论Gate1协议，不自动启动模型或2k探针**。seed43只有2个状态，仅能作为策略依赖预警，不能宣布跨策略验证通过。
- `Stop / Inconclusive`：12状态中的标签大量同为成功/失败、有效独立episode少、统计太稀、无法构造contact基线、B2/复现未完成或预算已到。明确是不足以判断必要性，**不是已证明方向无效**；不根据结果无限追加数据。

**不得**使用“样本结果翻转率<10%”或“新方法成功率改善<3pp”作为当前Gate0的普遍统计证伪定理。所有结果都只针对已测试的 Square、专家状态、控制器与特定冻结续跑策略。
