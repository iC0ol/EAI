# 修复与偏差

上游 KYC 与 RoboSuite 源文件没有编辑。实验直接导入冻结版本的 ACT、Dataset 和 delta wrapper，新脚本负责监督、恢复和评估。

`repair01_initial_root_restore.diff` 是新验收脚本的一项修复差异，由对话中实际执行的前后编辑重建；不是上游补丁或单独保存的原始文件快照。原验收在轨迹末状态使用 compiled XML，图像最大差异255；该问题的原因没有被证明。零动作诊断确认初始状态对两类XML均可精确恢复，修复后的验收改为与实际配对评估一致的“源码模型XML + 初始完整state”连续恢复。原失败结果及退出码保留，10条专家回放未重复计数。clean policy完整rollout额外重放一次，动作和成功结果完全一致。

另外记录但不掩盖：验证相机按协议改为训练pool；自定义可恢复sampler使用独立seed0生成器，RNG轨迹与官方DataLoader不完全相同；U接口阴性检查延至dev阶段，未训练U；对话中断前已提交训练，评估入口在五小时续查时完成并执行；smoke的两个滚动状态文件被正式训练更新，保留的smoke吞吐文件及日志可独立核验，原smoke权重没有永久归档。

真实相机移动方案已在任何test前冻结：绕官方名义workspace_center做10°方位角位移，再朝向该名义点。原相机有target jitter，因此实际旋转角另存；边界处在无结果时按几何反向。该方案本轮没有执行，后续研究者应审查这一协议解释后再授权使用。
