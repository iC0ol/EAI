1. **A1 的三个变量混淆了四个不同过程。**

## 第二部分 A1 的科学定义审查

### 2.1 因果链

对固定任务、固定策略 π、固定控制器 C、固定动作接口：

```
输入扰动 δ  →  策略动作响应 Δa = R_π δ  →  闭环任务误差 e_x(T) = P_c Δa  →  结果 Y = 1[ |e_x(T)| ≤ c ]
   (可选)              (感知→动作)                  (动作→状态)                         (几何判定)
```

`e_x(T)` 与 `c` 都取**沿关键约束方向的一维投影**（例如插入轴的毫米数、放置平面的法向距离）；多维情形需分别判定或取最紧方向。

这是**一阶局部线性化**。它在小扰动、无接触突变时近似成立；接触切换、抓取失败、策略重规划会破坏线性，必须作为模型的适用条件，而不是默认成立。

### 2.2 变量定义（与 A1 原符号的对应）

| 符号 | 定义 | 单位 | 观测方式 | 与 A1 原符号的关系 |
|---|---|---|---|---|
| `x_t` | 特权仿真状态 | — | 仿真器 | 原报告未显式 |
| `o_t = O(x_t; θ)` | 观测；θ 为相机位姿/分辨率/深度噪声 | — | 仿真渲染 | 原报告未显式 |
| `δ` | **受控的任务相关输入扰动**（例如把观测中的目标位置平移 δ 米） | m / rad | 实验者设定 | 原 `ε(s)` 的可操作替代；原 `ε` 是"估计误差"，端到端策略不可读 |
| `R_π(s)` | **策略响应敏感度** `∂a/∂δ`，固定状态与历史 | action / m | 同一状态配对扰动，测动作变化（共同随机数） | 原 `g` 的一半 |
| `P_c(s)` | **闭环传播增益** `∂e_x(T)/∂a_s`，含控制器与重规划 | task-error / action | 注入小动作扰动，测关键事件的任务误差 | 原 `g` 的另一半；2610.01626 测其标量版 |
| `c(x)` | **任务几何余量** `dist(φ(x), ∂A)`，A 为任务容许集 | m / rad | 解析几何或仿真碰撞/接触查询 | 原 `τ` 的一半；**策略无关** |
| `T_π(s)` | **策略闭环容差** `{δ : P(success | δ at s) ≥ p}` | m / rad | 闭环 rollout（行为量） | 原 `τ` 的另一半；**由成功率定义** |
| `Y` | 任务成功 | {0,1} | 任务谓词 | 原 `Δsuccess` |

其中 `φ(x)` 是任务相关的空间泛函（目标位姿、孔位、放置区域），`A` 是容许集。

### 2.3 感知误差、动作误差、任务误差必须分开

- **感知误差 `e_p`**：观测/估计与真实任务相关量的差。对端到端策略，内部估计不可读；只能通过**受控输入扰动 δ** 在输入侧定义。把 `e_p` 说成"策略的空间估计误差"是超出可观测性的。
- **动作误差 `e_a`**：执行动作与"正确动作"的差。可在配对扰动下测 `Δa`，或用 2610.01626 的动作注入测传播。
- **任务误差 `e_x`**：关键事件处任务相关状态与容许集的差。必须用特权状态测。
- 三者不是同一个量。A1 原 `ε(s)` 在"感知误差"和"任务误差"之间滑动；这是它无法被测量的根源。

### 2.4 任务几何余量 vs 策略闭环容差

| 问题 | 任务几何余量 `c(x)` | 策略闭环容差 `T_π(s)` |
|---|---|---|
| 由什么决定 | 目标尺寸、接触约束、碰撞边界、可达性 | 策略的反馈、重规划、控制器、任务几何 |
| 是否依赖策略 | 否 | 是 |
| 是否随阶段变化 | 是（关键事件处最小） | 是 |
| 需要什么观测 | 特权状态 + 几何/碰撞查询 | 闭环 rollout + 成功判定 |
| 能否干预前获得 | **能**（解析/仿真查询） | **不能**（需实验） |
| 与成功率的关系 | 定义容许集，不定义成功率 | 由成功率定义 |

**二者能否严格联系？** 只能在附加假设下：
- 在关键事件瞬间，若策略无法再修正，则 `T_π(s)` 不会超过 `c(x_T)` 所允许的范围；
- 在关键事件之前，策略可以运输/重抓，`T_π(s)` 可以大于 `c(x_s)`；
- 因此不存在无假设的通用上下界。把 `T_π` 当作 `c` 的函数，是把"策略能力"与"任务几何"混为一谈。

**结论**：A1 必须二选一：
- 用 `c(x)` 做**几何**分析（可解析、策略无关），但不能预测策略收益；
- 用 `T_π(s)` 做**行为**分析（需实验），但它是成功率的函数，不能反过来预测成功率而不循环。
A1 原式同时用了两者，且都叫 `τ`。

### 2.5 可测性矩阵（干预前 vs 必须实验）

| 量 | 干预前可测？ | 需要什么 | 备注 |
|---|---|---|---|
| `δ` | 是 | 实验者设定 | 输入侧；可选幅度/方向 |
| `c(x)` | 是（简单几何）/ 需仿真查询（接触/铰接） | 特权状态、碰撞查询 | 策略无关 |
| `R_π(s)` | **否** | 配对输入扰动 + 策略前向 | 需实验；可用共同随机数降方差 |
| `P_c(s)` | **否** | 配对动作扰动 + 闭环 rollout | 需实验；2610.01626 的协议可借鉴 |
| `T_π(s)` | **否** | 闭环扰动 rollout + 成功判定 | 由成功率定义；不能作预测自变量 |
| 干预后的 `δ'`、`ΔY` | **否** | 实施干预 | 这是结果，不是预测特征 |

**结论**：A1 若声称"预测"，只有 `c(x)` 是干预前纯解析可得的；`R_π`、`P_c` 需要实验测量。把 `R_π`、`P_c` 说成"干预前可测"是对的（在 Gate B 中测），但它们不是"读文献可得"的量。A1 的预测时点问题由此收窄：**预测的是"在已知 R_π、P_c、c 的情况下，降低 δ 是否值得"，而不是"不做事先测量就能预测"**。

### 2.6 定义循环与量纲错误

1. **`τ` 的循环**：`T_π(s)` 用成功率定义；用 `T_π(s)` 预测成功率，等于用结果预测结果。只有当 `τ` 被替换为几何 `c(x)` 时才不循环，但那时它不再包含策略能力。
2. **`g` 的量纲合并**：`R_π` 的单位是 action/m，`P_c` 的单位是 task-error/action；乘积才是 task-error/m。把二者合成一个无量纲 `g` 需要额外的归一化，而 A1 没有给出。不同任务的 action 空间尺度不同，`g` 不可跨任务比较。
3. **`ε` 的不可观测**：若 `ε` 指空间估计误差，端到端策略没有可读的目标位姿，把"模型意图中的目标位置"当作可测量是错误的；若 `ε` 指所选目标上的执行误差，它属于任务误差 `e_x`，不是感知误差。可测的是输入扰动 `δ` 与动作响应 `Δa`。

### 2.7 A1 是否值得保留

- **作为方法型候选：否。** 定义不成立；修正后是测量框架。
- **作为测量型候选：有条件保留。** 修正后的误差预算（`R_π · P_c / c`）是一个可检验的定量关系；没有论文直接测三者乘积并预测干预收益（本轮有界检索）。
- **作为毕业论文：可作为一章**，但不能支撑"独立方法创新"的小论文。

## 第三部分 新颖性审查：A1 是新机制还是组合

### 3.1 五个问题的回答

1. **任务几何容差是否已能解析计算？**
   是，对简单几何（槽宽、孔隙、放置区域）。MetaFine 的 `pos_eps=2e-2`、`rot_eps=4°`、`height_eps=3e-3` 就是硬编码的任务容差（`core/env.py:3684-3705`）；论文的任务规格用 `eps_pos_mm/eps_ang_deg`（Fig. A1）。铰接/接触任务需要仿真查询，但仍是几何量，不需要学习。

2. **动作扰动的闭环传播是否已有成熟研究？**
   是。经典控制/误差传播成熟；2610.01626 在 chunked policy 上测了 λ，发现状态依赖、78% lift stamps 在 deadband、闭环稳定罕见。APEX 进一步从执行侧补执行间隙（tracking error −41.2%）。A1 的 `P_c` 没有超出这些。

3. **视觉输入扰动 → 策略动作变化的敏感性是否已有现成方法？**
   是。ActGaze 用反事实视觉干预测 action relevance；EGR 用 per-frame/per-sensor evidence 门控 invariance/sufficiency；View Collapse 用 blackout/blur 测 per-view reliance；GAP 用梯度调整平衡模态；RRDF 用 phase-matched 探针测 state→image 敏感性。A1 的 `R_π` 是这些测量的一个特例。

4. **不确定性触发、自适应分辨率、按阶段分配是否已有成熟实现？**
   是。RAIN（按需细化）、VLA-Corrector（检测偏差后重规划）、ActFovea（运行时一致性）、FoveaVLA（foveation action）、ART-VS（自适应分辨率 tiling）、Look Where It Matters（自适应视觉细化）、MetaFine（阶段诊断）。A1 的"分配"没有超出这些的系统形态。

5. **组合是否只是工程集成？**
   **大部分是。** 三因子乘积是一个诊断模型；它把已有测量组合起来，能回答"哪个因子限制当前策略"，但不能产生新的行动能力。要成为方法，必须改变一个因子；而改变因子的手段已被 EGR/APEX/MetaFine/ActGaze 占据。

6. **缺少哪一种新理论关系、估计机制或行动决策方法？**
   - 新理论关系：`R_π · P_c / c` 的定量预测律（测量型）；
   - 新估计机制：在线估计 `R_π`/`P_c`/`c`（工程/估计型，非全新）；
   - 新行动决策：margin-conditioned sensitivity/equivariance（与 EGR 只差门控信号）。
   三者都没有形成"现有方法不能实现的能力"。

### 3.2 三种方案对比

| 方案 | 代表 | 能做什么 | 不能做什么 | 与 A1 的差异 |
|---|---|---|---|---|
| A 解析/控制 | 任务几何 + 雅可比 + 控制器模型 + APEX | 算 `c`、`P_c`；补执行间隙 | 不能预测策略的 `R_π`；不能处理学习策略的接触突变 | A1 的 `c`/`P_c` 部分已被覆盖 |
| B 简单学习/视觉 | EGR、ActGaze、GAP、View Swap、MetaFine 编码器、Pix2Act | 改变信息使用/表征/注意力；提升鲁棒性或精度 | 不测三因子乘积；不按几何余量分配 | A1 的方法变体与它们同族 |
| C A1 新机制 | margin-conditioned sensitivity/equivariance | 若成立，可按余量塑造敏感性 | 与 EGR 的门控机制同构；无证据优于 EGR/ActGaze；无独立基准 | **不构成独立机制** |

### 3.3 结论

**A1 是"误差预算诊断"，不是"新方法机制"。** 它的科学价值在于把三个已知量放到同一个因果链上，检验哪一个限制当前策略；它的方法价值不足以支撑一篇方法型小论文。若用户接受测量型论文，A1 可以作为论文；若坚持方法创新，A1 不合格。

## 第六部分 简单方法与新机制对比

### 6.1 最强解析/控制方法

- 任务几何 + 雅可比 + 控制器模型：算 `c`、`P_c`；对简单任务足够。
- APEX：执行间隙的 plug-and-play 适配，tracking error −41.2%，success +4.8–25.8 pp，含 ACT。
- 若 A1 的失败主要来自 `P_c`，APEX 是强替代；若来自 `c`，解析几何足够；若来自 `R_π`，才轮到学习/训练方法。

### 6.2 最强简单学习/视觉方法

- EGR：证据门控的 invariance/sufficiency，直接改变信息使用。
- ActGaze：动作接地 gaze，直接改变空间注意。
- MetaFine encoder intervention：直接改变视觉编码器的局部空间保真。
- FTM/FLA：测试时 4K/4.7M 参数适配，恢复跨视角。
- Pix2Act：等变增广。
- 这些方法在"改变信息使用"上与 A1 的 margin-conditioned 变体同族；A1 只多了"用几何余量做门控"这一点。

### 6.3 潜在新方法（A1 修正版）

- **margin-conditioned sensitivity/equivariance**：在紧余量状态要求动作对任务相关扰动敏感，在松余量状态允许不变。
- 与 EGR 的差异：门控信号从"可见性/接触"换成"几何余量"；目标从"模态使用"换成"动作增益"。
- 科学差异是否足够？**不足**：机制同构（门控一致性目标），证据基础相同（信息使用失败），没有新的理论关系；EGR 已经证明这条路线可行，A1 只是换信号。
- 若强行做，必须证明：在同等数据/算力下，margin gate 比 evidence gate 更能提升精度阶段成功率，且增益由 `R_π` 的基线缺陷预测。这是 Gate B/C 的问题，不是本轮能裁定的。

### 6.4 对照用户给出的三种方法形态

| 方向 | A1 能否形成 | 为什么 |
|---|---|---|
| **方向一：新的空间误差估计/传播机制** | 只能形成**测量**，不是新估计器 | 解析几何 + 雅可比 + 2610.01626 的 λ 已覆盖 `c`/`P_c`；A1 的组合是诊断，不是更可靠的估计机制 |
| **方向二：新的空间信息使用/决策机制** | 与 EGR/ActGaze 同族 | 把门控信号从可见性/接触换成几何余量；机制同构（门控一致性目标），没有新的决策原理 |
| **方向三：新的任务约束感知行动机制** | 与 APEX/安全过滤重叠 | 执行间隙由 APEX 处理；空间约束由 CBF/安全过滤处理；A1 没有新的约束满足机制 |

**结论**：三种形态都没有给出"现有方法不能实现"的能力；A1 的独立贡献只在测量/诊断层。

### 6.5 结论

A1 的方法与 EGR/ActGaze/APEX 没有本质区别；它的测量部分有独立价值，但不足以支撑方法型小论文。

### 7.1 B3 早退

### 7.3 逐个判定

- **A1**：保留为**测量型**候选；不作为方法型小论文。它的科学问题（三因子乘积是否预测收益）是可检验的，但没有独立方法机制。

### 8.2 统计单元与设计（若未来做测量）

- **统计单元**：状态（同一 episode 内的决策点）→ episode（同一任务/seed）→ 任务（外部效度）。三者不能混用；状态间强相关，必须用按 episode/task 聚类的 bootstrap 或分层模型。
- **配对**：同一物理初态、同一动作噪声、只改输入扰动；MetaFine 的 `episode_seeds` 跨 profile 复用可作为起点，但相机扰动需显式播种/固定方向。
- **选择偏差**：不能用"成功轨迹"估计 `c`/`P_c`；必须用全部 rollout，并条件在"到达该阶段"的暴露上（报告 stage exposure）。
- **扰动后状态分布变化**：扰动会改变后续状态分布；比较必须条件在阶段到达，或使用 g-computation/重加权；否则把"到不了阶段"误读为"精度失败"。
- **功效**：用 pilot 方差估最小可检测效应；"效应 > 2× 种子噪声"是**工程余量**，不是科学定律；不能写成通过/不通过的科学阈值。
- **外推**：留一任务/留一阶段报告每任务结果，不把 n=5 的 Spearman 当普遍规律。

### 8.3 删除的任意阈值

- 删除"τ 阶段差异 >2× 才继续"作为硬门槛；改为"用 pilot CI 估可分辨性，CI 跨零则停止"。
- 删除"3 个任务 Spearman |ρ|<0.3 停止"；n=5 时 ρ 的标准误约 0.45，该阈值无判别力。
- 删除"效应 >2× 种子噪声"作为科学判据；保留为工程预算约束，并说明理由。
- 删除"top-k 选择效用"作为小样本门槛；2610.29646 的单元是 80 个留出语料，n=5 任务不可估计。

## 第九部分 小论文与毕业论文的连续性

### 9.1 若坚持 A1：测量型小论文 + 在线估计毕业论文

- **小论文（测量型）**：三因子误差预算 `R_π · P_c / c` 的测量与预测；在 2–4 个 MetaFine/ACT 任务上检验它是否解释干预收益；贡献是"诊断/预测"，不是方法。必须与 EGR/APEX/MetaFine 划清边界。
  - 具体问题：*Does the error-budget product `R_π · P_c / c` predict the action benefit of a spatial precision intervention across tasks/stages, and which factor limits current policies?*
  - 最小贡献：一个可复用的测量协议 + 一个预测关系 + 对"哪个因子主导"的实证结论；**不提出新策略、不提出新训练目标**。
  - 必须击败：解析几何基线、headroom、任务身份、EGR/ActGaze 式信息使用基线、APEX 式执行基线。
- **毕业论文（新问题）**：**在线**估计 `R_π/P_c/c`（无特权状态）+ 切换成本下的分配。新问题不是"离线变在线"本身，而是：
  - 在线估计在部分可观测下的可辨识性；
  - 切换成本（延迟、抖动、观测中断）对分配收益的影响；
  - 误估导致的错误分配如何传播。
  这些是新的理论/技术挑战，不是换数据。
- **风险**：若小论文的三因子与任务身份共线，或 EGR/APEX 已覆盖，毕业论文主线不成立；不能靠"再加模块"续命。

### 9.2 若坚持方法型小论文

- 本轮没有合格候选。A1 的方法变体与 EGR 同构；B1/B2/B3 更弱。
- 需要换问题域并重做 Gate A；本轮不提供"换域后一定成立"的保证。
- 换域的标准（建议）：
  1. 真实行动失败有稳定证据（≥2 个独立数据集/研究）；
  2. 现有最强方法（解析/学习）不能解释或修复；
  3. 新机制不是"门控/加权/适配"的变体；
  4. 3090 可做最小验证；
  5. 小论文与毕业论文有不同科学问题。
- 候选域（假设，未验证）：接触丰富精密装配（力/触觉）、铰接物体约束操作、移动操作基座—臂协同。每个都需要新的 Gate A；不要直接立项。

### 9.3 两篇论文的不同贡献（若走测量型）

- 小论文：测量/预测（离线、特权状态）。
- 毕业论文：在线估计 + 分配（部分可观测、切换成本）。
- 两者不是"换数据/加种子"；毕业论文必须引入新的可辨识性/稳定性问题。

### 10.1 选择

- B1/B2/B3 不作为候选。
- 本轮不申请 Gate B/C。

### 10.2 依据

1. **A1 原定义不可识别**：`ε` 不可观测、`g` 合并两个过程、`τ` 循环定义（§2）。
2. **A1 修正后是测量框架**：三因子乘积的预测未被直接做，但三因子各自已被做；方法变体与 EGR 同构（§3、§5）。
3. **MetaFine 已占据阶段诊断/几何容差/编码器瓶颈**，但没有 R_π/P_c/分配；它不是 A1 的完整替代，但足以让 A1 的"平台+诊断"部分不新（§4）。
4. **B1 方法空间饱和；B2 证据弱；B3 被大规模动作空间研究占据**（§7）。
5. **3090 可行**不是瓶颈；瓶颈是**方法机制的独立性**。

### 10.3 什么会改变答案

- 出现一篇论文，测量 `R_π · P_c / c` 并证明它预测干预收益，且提出一个非门控/非加权的新机制；
- 或出现一个稳定的、未被诊断的行动失败（≥2 个独立研究），其修复需要新的空间—行动机制；
- 或用户接受测量型论文，并把毕业论文的新问题定位在"在线可辨识性 + 切换成本"。

### 10.4 下一步（不实验）
