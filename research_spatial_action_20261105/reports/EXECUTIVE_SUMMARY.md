# 执行摘要（供研究者快速判断）

检索截止 2026-11-05。完整论证见 `reports/FINAL_REPORT.md`；证据见 `sources/papers.jsonl`。

## 结论（一句话）

**建议：暂不推荐立即立项。** 本领域"再做一个空间表征/空间接口"已无余地；唯一残留的入口是 C1——用基线失败模式构成（空间精度型 vs 跟踪/遮挡型）预测空间升级能否改变行动结果——但它的**方法论部件都已被分别做出来**：2608.03052 建立了"某输入是否/在哪些任务上有帮助"的受控范式（45 任务、5 接口、任务族差异），LIBERO-RIG 给出了精度—成功率阶梯，More Structure 证明了机制。C1 只剩把三者**组合成跨任务可外推的预测**——组合式贡献，评分 **3.1**、置信中低。

**为什么仍列出 C1**：它是唯一一个可以只读核查到底、且结论可证伪的问题；若其跨任务预测成立，可支撑一篇测量型小论文与后续"精度分配"毕业论。**为什么不建议直接开工**：七条准入门槛中的前三条（基线达标、任务变体可构造、阶段容差可区分）都尚未验证，而任何一条不成立都会让实验白做。

## 五个最重要的发现

1. **跨视角/坐标系问题基本结束。** 显式几何 + 机器人中心坐标 + 密集 token 已被证明足够，且作者自己声明"不是新架构"（GP^A, [2609.32762](https://arxiv.org/abs/2609.32762)）；CamVLA 甚至做到无需外参（[2607.05396](https://arxiv.org/abs/2607.05396)）。继续在这里找创新会被直接比较。
2. **"看到 ≠ 用上"是真实且被反复证实的现象，但修复机制已被三条线占住。** A-FAR 命名了 acquisition–exploitation gap（[2609.37292](https://arxiv.org/abs/2609.37292)）；CMA 证明"动作变了但选择没变"（20/64 可靠，[2609.27247](https://arxiv.org/abs/2609.27247)）；测试时诊断证明"证据充分却不改变选择"（[2609.22299](https://arxiv.org/abs/2609.22299)）。因此"再审计一次"不构成独立小论文。
3. **同一空间干预的收益在任务间差 1–30 pp，而解释它的两块拼图已经存在。** KYC +1.0…+27.0 pp（[2510.02268](https://arxiv.org/abs/2510.02268)）；SeeR-VLA 仿真 +6.4 / 真机 +32.5 pp（[2607.11498](https://arxiv.org/abs/2607.11498)）。More Structure 已证明空间 grounding 只修 Near-Miss（31%→2.5%）、不修 No-Grasp，且指出 StackCube（72% No-Grasp、SR 5.3%）需要时序一致性而非空间 grounding（[2607.09825](https://arxiv.org/abs/2607.09825)）；LIBERO-RIG 已有 "tolerance per axis" 表（[2610.18843](https://arxiv.org/abs/2610.18843)）。**剩下的空白只是把二者连成跨任务预测关系，而不是发现新机制。**
4. **收益差异可能只是"基线越低涨得越多"（第七轮新增，最需先排除）。** LIT 在同一 camera 扰动下：基线 16.40 的架构 +27.43、基线 82.16 的 +2.39（[2609.12641](https://arxiv.org/abs/2609.12641) Table II）。若"精度型失败比例"与基线成功率高度共线，C1 的三因素模型就是 headroom 的重述。**入门检查不是跑实验，而是先证明这两个量可分离。**
5. **"空间表征不足"可能只是对齐问题。** 4K 参数的 Feature Token Modulation 把 LIBERO 跨视角成功率 48.5%→87.1%，4.7M 参数版本超过 π0.5 LoRA（467M）（[2512.02902](https://arxiv.org/abs/2512.02902)）。任何"升级表征"的收益都必须先排除这一解释。**限定（第七轮）**：该方法是 one-shot adaptation，需要目标分布数据；对齐对照必须给同等数据预算才公平。

## 推荐继续只读核查的 1 个问题

**C1：失败模式构成能否预测空间表征升级的收益？**（原表述为“容差能否预测收益”，复核后已收窄）

- 需要先验证的假设：基线失败模式构成 b、有效误差下降 Δε、捷径依赖 s 三者能预测 Δsuccess，并在留出任务上外推；τ 只是中间量且必须阶段条件化。
- **已发现的反例（自查）**：朴素的"容差越小收益越大"被 KYC 自己的数据反驳——Lift 收益最大 (+27.0)，AssemblySquare 只有 +7.9。单因素不成立，必须改为失败模式构成 b + 有效误差下降 Δε + 捷径依赖 s。
- 引文核查已完成到可接受程度：KYC 的 28 篇施引中约 24 篇是视角鲁棒性变体（其余为标定/动作空间/分布偏移），LIBERO-RIG/CMA/RSB 的施引也没有“失败模式→收益”研究；2610.01626 取到 0 篇施引；**More Structure 的 S2 施引列表在第七轮取到（空列表），Google Scholar 精确标题查询亦无 "Cited by"（同法查 KYC 显示 22，说明解析有效）**。注意：OpenAlex 的 cited_by=0 不算证据——它对 KYC 同样返回 0。
- 评估标准：必须证明**选择效用**（top-k 任务选择优于随机/按难度），而不只是相关性——2610.29646 已证明可靠且相关的诊断可能没有增量决策价值（+0.059 nats，CI 跨零）。

## 主要风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 失败模式与任务身份共线 | 预测退化为"任务查表" | 必须构造同任务、不同失败模式的变体（加/不加自遮挡） |
| 机制已被他人证明 | More Structure 已单任务证明，审稿人会说"重复" | 只能靠留出任务预测；做不到就放弃 |
| 只是对齐问题 | 4K 参数调制即可恢复大部分跨视角性能 | 增设轻量对齐对照（4K 参数级） |
| 基线不可靠 | KYC 不发布权重；ACT 在 AssemblySquare 基线仅 10.8% | 阶段 0 准入检查：基线达标才继续 |
| 测量型论文不被认可 | 依赖导师/审稿人口味 | 预先确认；备选是把 C1 作为毕业论第一章 |
| 已有同构研究 | 已查 7 个种子与 Scholar 关键词，未发现同构工作；More Structure 的施引列表已取到为空 | 立项前用机构网络再查一次（S2 对新论文有索引滞后） |
| **收益只是 headroom**（第七轮新增） | 基线越低涨得越多，b 与基线成功率可能共线 | 零模型固定为 Δ̂=α(1−baseline)；b 与它 \|ρ\|>0.8 即停止 |
| **通用干预也全面有效**（第七轮新增） | LIT 真机三轴 +16.7/+16.7/+13.3，不区分失败模式 | 必须加入通用干预对照，"定向"结论才成立 |

## 申请实验前必须跨过的门槛

1. ACT/DP 基线在 2 个任务上达到论文量级（Lift ≥ 30%、Stack ≥ 20%），3 种子方差可接受；
2. 能构造"同任务、不同失败模式"的变体，且失败分类器在两类变体上判据一致；
3. 阶段条件 τ 在 ≥3 个任务间可区分（不能只测一个标量）；
4. **同等数据预算下**，轻量对齐对照（4K 参数级，one-shot）的收益显著低于被检验的空间升级；
5. 能以选择效用（而非相关系数）证明增量决策价值：top-k 任务选择的实际收益优于随机、按难度，**并优于 headroom 空模型 Δ̂=α(1−baseline)**；
6. 引文核查确认无同构工作（7 个种子已查、More Structure 施引为空；仍非穷举）；
7. 研究者明确接受"以测量与预测为贡献"的论文形态。

七条不同时满足，**不建议申请任何实验授权**。
