# 执行摘要（供研究者快速判断）

检索截止 2026-11-05。完整论证见 `reports/FINAL_REPORT.md`；证据见 `sources/papers.jsonl`。

## 结论（一句话）

**在这个领域，"再做一个空间表征/空间接口"已经没有论文空间；唯一还站得住的小论文入口是一句很窄的命题：用基线失败模式构成（空间精度型 vs 跟踪/遮挡型）预测空间升级能否改变行动结果。** 第二轮全文复核后，这个方向**novelty 薄、置信中低**——机制已被 More Structure 在单任务证明，容差已被 LIBERO-RIG 操作化，剩下的只有"跨任务预测"这一小块。若跨任务预测不成立，诚实的结论是**暂不推荐任何候选**。

## 四个最重要的发现

1. **跨视角/坐标系问题基本结束。** 显式几何 + 机器人中心坐标 + 密集 token 已被证明足够，且作者自己声明"不是新架构"（GP^A, [2609.32762](https://arxiv.org/abs/2609.32762)）；CamVLA 甚至做到无需外参（[2607.05396](https://arxiv.org/abs/2607.05396)）。继续在这里找创新会被直接比较。
2. **"看到 ≠ 用上"是真实且被反复证实的现象，但修复机制已被三条线占住。** A-FAR 命名了 acquisition–exploitation gap（[2609.37292](https://arxiv.org/abs/2609.37292)）；CMA 证明"动作变了但选择没变"（20/64 可靠，[2609.27247](https://arxiv.org/abs/2609.27247)）；测试时诊断证明"证据充分却不改变选择"（[2609.22299](https://arxiv.org/abs/2609.22299)）。因此"再审计一次"不构成独立小论文。
3. **同一空间干预的收益在任务间差 1–30 pp，而解释它的两块拼图已经存在。** KYC +1.0…+27.0 pp（[2510.02268](https://arxiv.org/abs/2510.02268)）；SeeR-VLA 仿真 +6.4 / 真机 +32.5 pp（[2607.11498](https://arxiv.org/abs/2607.11498)）。More Structure 已证明空间 grounding 只修 Near-Miss（31%→2.5%）、不修 No-Grasp，且指出 StackCube（72% No-Grasp、SR 5.3%）需要时序一致性而非空间 grounding（[2607.09825](https://arxiv.org/abs/2607.09825)）；LIBERO-RIG 已有 "tolerance per axis" 表（[2610.18843](https://arxiv.org/abs/2610.18843)）。**剩下的空白只是把二者连成跨任务预测关系，而不是发现新机制。**
4. **"空间表征不足"可能只是对齐问题。** 4K 参数的 Feature Token Modulation 把 LIBERO 跨视角成功率 48.5%→87.1%，4.7M 参数版本超过 π0.5 LoRA（467M）（[2512.02902](https://arxiv.org/abs/2512.02902)）。任何"升级表征"的收益都必须先排除这一解释。

## 推荐继续只读核查的 1 个问题

**C1：失败模式构成能否预测空间表征升级的收益？**（原表述为“容差能否预测收益”，复核后已收窄）

- 需要先验证的假设：基线失败模式构成 b、有效误差下降 Δε、捷径依赖 s 三者能预测 Δsuccess，并在留出任务上外推；τ 只是中间量且必须阶段条件化。
- **已发现的反例（自查）**：朴素的"容差越小收益越大"被 KYC 自己的数据反驳——Lift 收益最大 (+27.0)，AssemblySquare 只有 +7.9。单因素不成立，必须改为失败模式构成 b + 有效误差下降 Δε + 捷径依赖 s。
- 下一步只读工作：这四篇的**施引文献**仍未核查（OpenAlex 单篇元数据可用，但 citation filter 与 Semantic Scholar 均返回 429）。这是唯一可能推翻 C1 的检索缺口。

## 主要风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 失败模式与任务身份共线 | 预测退化为"任务查表" | 必须构造同任务、不同失败模式的变体（加/不加自遮挡） |
| 机制已被他人证明 | More Structure 已单任务证明，审稿人会说"重复" | 只能靠留出任务预测；做不到就放弃 |
| 只是对齐问题 | 4K 参数调制即可恢复大部分跨视角性能 | 增设轻量对齐对照（4K 参数级） |
| 基线不可靠 | KYC 不发布权重；ACT 在 AssemblySquare 基线仅 10.8% | 阶段 0 准入检查：基线达标才继续 |
| 测量型论文不被认可 | 依赖导师/审稿人口味 | 预先确认；备选是把 C1 作为毕业论第一章 |
| 已有同构研究 | 引文列表仍不可得（429） | 立项前用机构网络补检索 |

## 申请实验前必须跨过的门槛

1. ACT/DP 基线在 2 个任务上达到论文量级（Lift ≥ 30%、Stack ≥ 20%），3 种子方差可接受；
2. 能构造"同任务、不同失败模式"的变体，且失败分类器在两类变体上判据一致；
3. 阶段条件 τ 在 ≥3 个任务间可区分（不能只测一个标量）；
4. 轻量对齐对照（4K 参数级）的收益显著低于被检验的空间升级；
5. 引文核查确认无同构工作（或有但结论不同）；
6. 研究者明确接受"以测量与预测为贡献"的论文形态。

六条不同时满足，**不建议申请任何实验授权**。
