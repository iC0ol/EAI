# 容差、误差传播与“何时值得提升空间精度”

这是候选 C1 的文献基础与演变记录。**初始问题**：是否存在一个任务级量（容差 τ），能预测“提升空间表征/精度”会带来多少行动收益？**最终形态见文末修订**：τ 降为中间量，主自变量改为失败模式构成 b、有效误差下降 Δε 与捷径依赖 s。

## 2610.01626 Measuring the Stability Assumption Behind Action Chunking（FULL_TEXT）

- 证据：Abstract。
- 方法：在每个状态注入一个小动作误差，分别在开环（重放 chunk）与闭环（重新规划）下测量误差收缩/放大速率；拟合速率把状态标为 contracting / expanding / unresolved。
- 结果：12 个操作任务、3 个基准套件；确信稳定的状态很少，放大很常见；放大是“前置集中”的，短窗口会高估长时程传播；开环速率可从相机+本体预测，闭环速率只能部分预测。
- 与 C1 的区别：它测量**动作误差在时间上的动力学**，不测量**任务对空间误差的容忍阈值**，也不把阈值与表征收益挂钩。但它是“注入已知误差、测响应曲线”的直接方法学前身。

## 2610.18843 LIBERO-RIG（FULL_TEXT）

- 证据：Abstract；Fig. 1；严重度定义。
- 11 条硬件/设置扰动轴 × 5 个严重度 × 4 个 LIBERO 套件，每条件 500 episodes，9 个 VLA。
- 数字：总体成功率 0.932 → 0.767（中severity）→ 0.509（最高）。
- 关键发现：不同扰动轴与动作接口的退化差异很大；**对视觉扰动做训练并不能缓解“不改变图像”的故障**。
- 与 C1 的区别：它给的是“轴 × 严重度”的总体曲线，不估计每任务的 50% 失败阈值，不做失败模式归因，也不预测“换表征能挽回多少”。它可以作为 C1 的基线与对照设计模板。

## 2603.26779 Limits of Spatial Imagery Reasoning in Frontier LLM Models（ABSTRACT_ONLY）

- 仅摘要级；提示“空间想象推理”存在上限。未用于强结论。

## 2607.03758 Tolerance-aware manipulation（FULL_TEXT）

- 证据：Abstract；§1。
- “tolerance”在规划语境中指**目标区域可行集**：只要落在抓取区域内就算成功，而非追踪精确位姿。
- 这确认了术语冲突：机器人学的 tolerance = 可行域；C1 的 tolerance = **任务对空间误差幅度的容忍度**（dose–response 阈值）。两者相关但不同，写作时必须显式定义以免混淆。

## 2607.09825 的 oracle 上界（FULL_TEXT）

- 完整系统 68.7% vs 特权 3D oracle 71.7%：差距仅 3 pp。
- 这提示一个可检验的“饱和”假设：当策略已接近 oracle，继续提升空间表征的收益趋近于零；此时真正的瓶颈转移到执行/接触/控制。

## 2510.02268 KYC 的任务间差异（FULL_TEXT）

- 同一干预（相机条件化）在六个任务上增益 +1.0 到 +27.0 pp（Lift +27.0、PickPlaceCan +4.2、AssemblySquare +7.9、Push +7.6、LiftUpright +11.7、RollBall +1.0）。
- 若 C1 成立，这种差异应能被任务容差解释：Lift 通常是宽容差任务却增益最大（+27.0），AssemblySquare 是紧容差任务却只有 +7.9，**方向与朴素预期相反**。
- 这是一个重要的反例：增益大小可能更多取决于**基线是否依赖捷径**（fixed 场景背景）而非任务容差。C1 必须把“捷径可利用性”作为竞争解释纳入设计，否则会被审稿人一击致命。

## 复核补充（第二轮全文阅读，2026-11-05 晚）

### LIBERO-RIG 的 Table 5 已经定义了“每轴容差”

第二轮读全文时发现：LIBERO-RIG 的 Table 5 标题即 "Tolerance per axis"，定义为**每个模型在该轴上首次失败前能通过的最严严重度**，使用两个判据（绝对成功率 ≥0.80；相对自身 nominal 的 ≥0.90）。这说明 **“容差”这个概念在基准层面已被操作化**，C1 不能声称首次提出容差测量。

但 Table 5 有三条明确限制，恰好留下 C1 的空间：
1. 容差是**按轴**（相机安装、标定、控制频率……），不是按任务几何；
2. 作者明说 "Levels are set per axis, so the table compares models within an axis, not axes with one another"——**跨轴/跨任务不可比**；
3. 它只测“模型在哪一级失败”，不测“换一个空间表征能挽回多少”。

因此 C1 必须收缩为：**以失败模式构成（b）为主、容差作为阶段条件中间量，且用于预测表征升级的收益**；不能复用“严重度等级”作为容差。

### More Structure 给出了“同一干预只修一种失败模式”的直接证据

全文数据（Table I 与 Fig. 4）：
- Pure visual 31.0% → 加 2D 目标投影 55.0%（+24）→ 精确标定 58.7%（+3.7）→ 原分辨率渲染 68.7%；3D oracle 71.7%。
- Near-Miss（空间精度）失败从 31% → 21% → **2.5%**；No-Grasp（物体跟踪）失败在三种条件下为 15 / 15 / 24（每 200 集），**完全不受空间 grounding 影响**。
- 换到 StackCube-v1：同一架构迁移后成功率仅 5.3%，**72% 是 No-Grasp**（手臂自遮挡）；作者据此指出该任务需要时序 slot 一致性而非更多空间 grounding。注意：**论文并未在 StackCube 上做空间干预对照**，这是推断而非实验结论。

这比“容差”更精确地说明了机制：**收益取决于基线失败中“空间精度型”失败所占比例，以及干预是否真的降低该误差**。它同时解释了为什么同一个干预在不同任务上收益可以从 +1 到 +27 pp。

### 2610.01626 反驳“单一全局速率/阈值”

全文限制节明确写道：即使在同一任务内，误差传播速率也随状态大幅变化，"the assumption of a single global contraction rate is not supported empirically even at the task level"。因此 **把 τ 当作每任务一个标量在方法上是有问题的**，C1 必须把 τ 定义为状态/阶段条件分布，或至少在阶段层面测量。

## 结论（已修订）

C1 的文献基础存在，但**朴素版本（容差越大收益越大）已被 KYC 的任务间模式部分反驳**，且“容差”已被 LIBERO-RIG 操作化。因此 C1 必须重构为：

> 空间表征升级的行动收益 = f(基线失败中空间精度型失败的比例 b, 干预是否真正降低有效空间误差 Δε, 基线对捷径的依赖 s)。
> 只有当干预降低了**当前主导失败模式**所对应的误差时，收益才出现；若主导失败是遮挡/跟踪（No-Grasp），空间精度类干预无效。

这是一个三因素假设（b, Δε, s），可在 6–8 个任务上做预测—留出验证；它比“容差预测收益”更贴近 More Structure 的机制证据，也更能解释 KYC 与 StackCube 的反例。τ 仍作为中间量测量，但不再是唯一自变量，且必须是阶段条件化的。
