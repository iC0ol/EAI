# 决策层审计：2609.27247 / 2609.22299 / 2609.28955 / 2604.18000 / 2607.13618 / 2609.26567

这一簇是本次调研最重要的发现：**“行动变了”与“决策用上了证据”不是一回事**，而且已经在多个独立设置中被证实。

## 2609.27247 Counterfactual Memory Audit（FULL_TEXT）

- 作者：未逐一记录（HTML 首部未完整提取作者列表，登记表中保留 arXiv 元数据）。
- 证据：Abstract；Table 3；§V。
- 设计：把两条历史在“已验证一致的当前输入”处交叉，用公共随机数查询冻结策略，再把同一动作放到两种历史下评估。分解为 memory sensitivity / warranted choice / matched-world value / per-pair reliability。
- 数字：
  - Mem-0 上 Put Back 每一对动作都改变，但只有 **20/64** 对完全可靠。
  - 真机上 9 次完成的 Put Back 中 **5 次抓错目标**。
  - 动作种子间差异 **0.0674 rad**（关节 RMS），远大于记忆交换造成的差异 **0.0076 rad**。
  - 恢复一个 4096 字节保护锚点可挽回 **38.9 分**的 Swap 成功率。
- 含义：任何“干预改变了动作”的主张，都必须先证明效应大于种子噪声；否则是噪声。

## 2609.22299 When Does Test-Time Physical Diagnosis Pay?（FULL_TEXT）

- 六条有序条件：有意义的参照、物理条件可辨识、证据被使用、决策价值、相对固定替代方案的选择价值、安全实现。
- 结果：迁移到未见机构后，链条在“**证据使用**”处断裂——冻结解码器不改变选择；而只用 trace 增量的线性模型能在留出机构上恢复正确选择。失败集中在“证据最丰富”的决策层。
- 含义：这是“信息充分但未被使用”的最强单点证据，且给出了可复用的六条件评估框架。

## 2609.28955 ActGaze（FULL_TEXT）

- 用反事实视觉干预学习“动作相关的注视”。LEGO 装配：干净 18/20 vs 19/20；杂乱 13/20 → 15/20；强光照 11/20 vs 11/20。
- 含义：反事实视觉干预**可以**改变行为，但收益限于空间干扰项，对全局外观变化无效；单元格 n=20，效应小。

## 2604.18000 Unmasking the Illusion of Embodied Reasoning（FULL_TEXT）

- BeTTER 基准，用因果干预（移除目标、预置物体）暴露“行为惯性”与“本体感觉过拟合”：策略会在缺失物体位置做 air grasp，或在视觉/本体冲突时冻结。
- 含义：策略在冲突下依赖序列先验而非验证场景；这与 2602.12032 的“本体感觉主导”互相印证。

## 2607.13618 STOCKTAKE（FULL_TEXT）

- 供应链 POMDP，用精确 Bayes filter 作为公平 oracle。四个模型中两个低于 symptom-blind 基线，但仍能识别 84–88% 的隐藏故障。
- 含义：方法学上的“知道—做到”分离（stated-belief detection lag / knowing-doing rate），可迁移到机器人但本身不是机器人证据。

## 2609.26567 Auditing visual experience retrieval（FULL_TEXT）

- 执行“每个经验 × 每个查询场景”的完整表；发现视觉最近邻规则在场景内排序接近随机（K=50 时 5 个嵌入中 4 个 AUROC 0.45–0.52），尽管配对成功预测 AUROC 可达 0.96。
- 含义：**相似度指标在配对层面有效，在决策层面无效**——与本题“表征指标好但行动不变”同构。
